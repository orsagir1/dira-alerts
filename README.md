# התראה על הגרלות "דירה בהנחה"

בודק כל 30 דקות את https://dira.moch.gov.il/ProjectsList ושולח פוש לטלפון (דרך ntfy) כש"מספר הגרלות פתוחות" עולה מ-0.

## הקמה (כ-5 דקות)

1. **אפליקציית ntfy** – להתקין בטלפון (App Store / Google Play), ללחוץ "+" ולהירשם לנושא עם שם ייחודי שקשה לנחש, למשל `dira-or-8f3k2q`.
2. **ריפו ב-GitHub** – ליצור ריפו חדש (עדיף Private) ולהעלות אליו את כל הקבצים, כולל התיקייה `.github/workflows`.
3. **Secret** – בריפו: Settings → Secrets and variables → Actions → New repository secret
   - Name: `NTFY_TOPIC`
   - Value: שם הנושא מסעיף 1
4. **הרצת בדיקה** – לשונית Actions → "Check dira lotteries" → Run workflow. אמור להגיע פוש "הבדיקה עובדת ✅" עם המספר הנוכחי.

מכאן זה רץ לבד.

## מתי מקבלים התראה
- 🏠 **נפתחו הגרלות** – פעם אחת, כשהמספר עובר מ-0 למספר גדול מ-0 (התראה דחופה).
- ⚠️ **הבדיקה נכשלה** – פעם אחת אם האתר לא נטען או שהמבנה שלו השתנה. במקרה כזה יש צילום מסך של הדף בתוצאות הריצה תחת Artifacts → debug-screenshot.
- ✅ **חזר לעבוד** – אחרי כשל, כשהבדיקה מצליחה שוב.

## איך זה עובד
- `check_dira.py` פותח את הדף בדפדפן Chromium אמיתי ובלי מסך (Playwright), כי האתר נבנה ב-JavaScript והמספרים לא מופיעים ב-HTML הגולמי. הוא מחפש את הטקסט "מספר הגרלות פתוחות" ולוקח את המספר שלידו.
- הערך האחרון נשמר ב-`state.json`, כדי שלא תקבלי התראה כל חצי שעה.
- `.github/workflows/check.yml` מריץ את הסקריפט ב-GitHub Actions לפי לוח זמנים (חינם לגמרי בריפו Public, ובריפו Private יש מכסה חינמית שמספיקה).
